주석문, 변수, 연산자, 자료형 확인 페이지

자바스크립트에서 변수 만들 때 사용하는 예약어(keyword) 3가지

  1. var 변수명 = 값;
    • ES5 이전부터 사용된 전통적인 변수 선언 방식
    • 지역변수로 선언된 경우, 함수 {} 안에서만 사용 가능한 변수가 됨
    • 같은 이름으로 변수 중복 선언 가능함
    • var 변수명; 선언할 수 있음 - 변수에 기록 저장한 값이 없으면 undefined 로 표시됨

  2. let 변수명 = 기록할값;
    • ES6 (ECMAScript 2015) 에서 도입
    • 지역변수로 선언된 경우, 선언된 {} 안에서만 사용 가능한 변수가 됨 (블록 스코프)
    • 같은 이름으로 변수 중복 선언 못 함
    • let 변수명; 선언할 수 있음 - 변수에 기록 저장한 값이 없으면 undefined 로 표시됨

  3. const 변수명 = 값;
    • ES6 에서 도입
    • 지역변수로 선언된 경우, 선언된 {} 안에서만 사용 가능한 변수가 됨 (블록 스코프)
    • 같은 이름으로 변수 중복 선언 못 함
    • const 변수명; 선언할 수 없음 - 에러 발생

ES6 (ECMAScript 2015)

자바스크립트 언어 표준 중 가장 많은 변화를 가져온 버전임

정보통신, 전자 시스템, 프로그래밍 언어 등의 국제적인 표준을 지정함
오늘날 웹과 클라우드 컴퓨팅 핵심 기술 기반을 표준화하는 단체임

자바스크립트 연산자 : === 연산자, !== 연산자 확인

== : 값이 일치하는지 비교함, === : 값과 자료형 둘 다 일치하는지 확인할 때 사용함

자바스크립트에서 문자열 다루기 : string 내장 객체의 메소드 사용

사용형식 : 문자열변수.메소드(), 문자열변수.속성, 문자열변수 대신에 문자열값을 바로 사용해도 됨

문자열과 숫자의 + 연산

문자열 + 숫자 => 문자열이 됨
숫자 + 숫자 + 문자열 => 숫자 두 개가 먼저 계산되고, 그 결과와 뒤의 문자열이 합쳐짐 => 문자열이 됨
