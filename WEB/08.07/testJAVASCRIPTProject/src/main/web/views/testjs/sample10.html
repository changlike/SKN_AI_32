회원 가입 : 유효성 검사 적용

유효성 검사는 form 의 입력값들이 기록 완료되고, 전송되기 전에 검사함 : 전송(submit) 버튼 누르면(onsubmit) 유효성 검사하고 나서 전송보냄

이벤트 적용은 2가지 방법이 있음, submit 버튼에 onclick 적용 또는 form 에 onsubmit 적용임
