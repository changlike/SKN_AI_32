자바스크립트 작성 위치와 작성 방법

자바스크립트 코드 작성 위치

  1. 인라인 방식 :

    시작태그명에 on이벤트종류 라는 속성을 추가하고, 값에 자바스크립트 코드를 직접 작성해서 기능이 작동되도록 하는 방법
    on이벤트종류 속성은 자바스크립트가 제공하는 속성이며, 모든 태그에 사용할 수 있음
    이벤트는 키보드나 마우스 동작을 의미함

     
  2. internal 방식 : script 태그 안에 함수(function)를 작성해서 함수 영역 안에 자바스크립트 코드를 작성하는 방식 (기본)

    script 태그의 작성 위치는 head, body, html 밖 어디에든 작성 가능하며, 여러 번 사용해도 됨
    script 태그 안에서 작성된 함수는 태그에 on이벤트종류 속성을 추가해서, 작성된 함수를 실행시킴
    <태그명 on이벤트="함수이름();">
    또는 script 태그 안의 다른 함수가 작성된 함수를 실행할 수도 있음

  3. external 방식 : 별도로 자바스크립트 소스 파일(*.js) 을 작성해 두고, 필요한 웹문서(html, jsp, asp, php 등)를 가져다가 소스 코드를 이용하는 방식

    별도로 작성된 js 파일을 웹문서에서 가져다 사용할 경우에는 script 태그를 사용함
    script 태그에 src 속성을 추가해서, js 파일의 경로 포함 파일명.js 를 값으로 지정하면 됨
    src 속성을 사용한 script 태그 안에는 코드 작성할 수 없음
    src 속성을 사용한 script 는 주로 head 영역에 작성함
