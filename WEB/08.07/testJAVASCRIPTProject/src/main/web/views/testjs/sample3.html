작동 원리는 논리연산자(&&, ||)의 성질을 이용하는 것임
&& 연산자 : 이항(계산값이 2개 필요 - 논리값 && 논리값) 연산자임, 둘 다 true 일 때만 결과가 true 임, 나머지 결과는 모두 false 임
|| 연산자 : 이항(논리값 || 논리값) 연산자임, 비교되는 값이 하나만 true 이면 결과는 true 임, 둘 다 false 일 때만 false임
&& 특징 : 앞이 false 이면 뒤를 계산 안 함, 앞이 true 이면 뒤를 확인함
|| 특징 : 앞이 true 이면 뒤를 계산 안 함, 앞이 false 이면 뒤를 확인함
