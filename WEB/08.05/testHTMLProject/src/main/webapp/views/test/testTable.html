table 태그 : 표의 가로와 세로 형태로 간격을 동일하게 컨텐츠를 배치할 때 사용하는 태그

table 태그의 속성(attribute) :
  1. border="테이블테두리선굵기", 단위는 픽셀(pixel), 기본값은 0 (테두리선 안 보임)
  2. width="테이블가로너비", 단위는 픽셀(pixel), 크기 지정없으면 칸(cell)에 기록되는 컨텐츠(글자, 그림) 크기에 맞춰짐
    3. 각 칸의 너비는 테이블의 width / 칸수로 기본 지정됨
  3. height="테이블세로높이", 단위는 픽셀(pixel)
    4. 각 줄의 높이는 테이블의 height / 줄수로 기본 지정됨
  4. cellspacing="셀과 셀사이의 간격", 단위는 픽셀, 0 지정은 간격을 없애는 것임
    5. 한 칸을 셀(cell) 이라고 함
  5. cellpadding="셀 안쪽 여백", 단위는 픽셀
    6. 주의 : 칸(cell)의 가로와 세로 크기를 고려해서 여백을 지정해야 함
  6. align="left | center | right", 브라우저 페이지에서의 표의 수평 위치 지정 (기본은 left 임)
  7. 추가 속성 : bgcolor="표전체배경색", background="표전체배경이미지.확장자", css 에서 주로 설정하므로 속성으로는 사용 안 함
