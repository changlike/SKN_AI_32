 **PyCharm에서 `final` 폴더 하나를 열되, Django와 FastAPI 각각에 `.venv`를 만들고 Run Configuration별로 다른 Python Interpreter를 지정**하는 방법

## 1. 권장 폴더 구조

먼저 Windows에서 다음과 같이 구성합니다.

```text
C:\web_workspace\final
│
├─ django_web
│   ├─ manage.py
│   ├─ config
│   ├─ members
│   ├─ boards
│   ├─ rag
│   ├─ requirements.txt
│   └─ .env
│
└─ fastapi_ai
    ├─ app
    │   ├─ __init__.py
    │   └─ main.py
    ├─ docs
    ├─ requirements.txt
    └─ .env
```

PyCharm에서는 각각의 하위 프로젝트가 아니라 상위 `final`을 엽니다.

```text
File
 → Open
 → C:\web_workspace\final
```

---

# 2. Django용 가상환경 생성

PyCharm 하단의 **Terminal**을 엽니다.

먼저 Django 프로젝트로 이동합니다.

```powershell
cd C:\web_workspace\final\django_project
```

다음 명령으로 Django 전용 가상환경을 만듭니다.

```powershell
py -3.11 -m venv .venv
```

그러면 구조가 다음처럼 됩니다.

```text
django_web
│
├─ .venv
├─ manage.py
├─ members
├─ boards
└─ ...
```

활성화합니다.

```powershell
.\.venv\Scripts\Activate.ps1
```

정상적으로 활성화되면 터미널 앞에 보통 다음과 같이 표시됩니다.

```text
(.venv) PS C:\web_workspace\final\django_web>
```

Django 프로젝트의 패키지를 설치합니다.

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Python 위치를 확인합니다.

```powershell
python -c "import sys; print(sys.executable)"
```

다음처럼 나와야 합니다.

```text
C:\web_workspace\final\django_web\.venv\Scripts\python.exe
```

---

# 3. FastAPI용 가상환경 생성

현재 Django 가상환경을 종료합니다.

```powershell
deactivate
```

FastAPI 프로젝트로 이동합니다.

```powershell
cd C:\web_workspace\final\fastapi_ai
```

FastAPI 전용 가상환경을 생성합니다.

```powershell
py -3.11 -m venv .venv
```

활성화합니다.

```powershell
.\.venv\Scripts\Activate.ps1
```

패키지를 설치합니다.

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Python 위치도 확인합니다.

```powershell
python -c "import sys; print(sys.executable)"
```

결과는 다음이어야 합니다.

```text
C:\web_workspace\final\fastapi_ai\.venv\Scripts\python.exe
```

결과적으로 가상환경이 완전히 분리됩니다.

```text
final
│
├─ django_web
│   └─ .venv
│       └─ Scripts
│           └─ python.exe
│
└─ fastapi_ai
    └─ .venv
        └─ Scripts
            └─ python.exe
```

# 4. PyCharm에 Django Interpreter 등록

이제 생성한 두 Python을 PyCharm에 등록합니다.

PyCharm 버전에 따라 메뉴 이름이 조금 다를 수 있지만 일반적으로:

```text
File
 → Settings (설정)
 → Python 
 → Interpreter
```

로 이동합니다.

`Add Interpreter`(인터프리터 추가)를 선택합니다.

그다음 **기존 환경(Existing environment / Existing)** 을 선택하여 Django의 Python을 지정합니다.

```text
C:\web_workspace\final\django_web\.venv\Scripts\python.exe
```

---

# 5. FastAPI Interpreter도 등록

같은 방법으로 다시:

```text
Settings
 → Python Interpreter
 → Add Interpreter
 → Existing
```

FastAPI의 Python을 선택합니다.

```text
C:\web_workspace\final\fastapi_ai\.venv\Scripts\python.exe
```

그러면 PyCharm에서 두 Interpreter를 사용할 수 있습니다.

```text
Django Python 3.11
    ↓
django_project\.venv\Scripts\python.exe

FastAPI Python 3.11
    ↓
fastapi_project\.venv\Scripts\python.exe
```

여기서 중요한 점이 있습니다.

**PyCharm 프로젝트 전체에 동시에 두 개의 기본 Interpreter가 적용되는 것은 아닙니다.**

그래서 실제 실행할 때는 **Run Configuration별로 Interpreter를 다르게 지정**하는 것이 가장 중요합니다.

---

# 6. Django Run Configuration 만들기

상단 메뉴에서:

```text
Run
 → Edit Configurations...(구성 편집...)
```

를 선택합니다.

`+` 버튼을 누르고 Django 지원이 활성화되어 있다면: 
(이미 존재할 수도 있음: 왼쪽 Django Server 아래 final)

```text
Django Server
```

를 선택합니다.

예를 들어 다음처럼 설정합니다.

```text
Name: 이름 바꾸기함
Django 8000

Host:
127.0.0.1

Port:
8000

Working directory:
C:\web_workspace\final\django_web

Python Interpreter:
즉 반드시 Django `.venv`를 선택합니다.

```text
C:\LLM_workspace\final\django_project\.venv\Scripts\python.exe
```


```text
Script path:
C:\web_workspace\final\django_web\manage.py

Parameters:
runserver 8000

Working directory:
C:\web_workspace\final\django_web

Python Interpreter:
C:\web_workspace\final\django_web\.venv\Scripts\python.exe
```

실제로 실행되는 명령은 다음과 같은 의미입니다.

```powershell
python manage.py runserver 8000
```

---

# 7. FastAPI Run Configuration 만들기

다시:

```text
Run
 → Edit Configurations...
 → +
 → Python
```

을 선택합니다.

FastAPI는 `uvicorn`을 모듈로 실행하는 방법이 편리합니다.

설정을 다음과 같이 합니다.

```text
Name:
FastAPI 8001

Run:
Module name

Module name:
uvicorn
```

Parameters:

```text
app.main:app --host 127.0.0.1 --port 8001 --reload
```

Working directory:

```text
C:\web_workspace\final\fastapi_ai
```

Python Interpreter:

```text
C:\web_workspace\final\fastapi_ai\.venv\Scripts\python.exe
```

결국 다음 명령과 동일합니다.

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --reload
```

여기서 특히 중요한 것은 FastAPI 실행 Configuration에 **Django Interpreter를 선택하면 안 된다는 것**입니다.

# 8. 최종 Run Configuration 구조

PyCharm 오른쪽 위 실행 목록에 두 개가 생깁니다.

```text
┌─────────────────────────────┐
│ Django 8000                 │
│                             │
│ Interpreter                 │
│ django_web\.venv        │
└─────────────────────────────┘

┌─────────────────────────────┐
│ FastAPI 8001                │
│                             │
│ Interpreter                 │
│ fastapi_ai\.venv       │
└─────────────────────────────┘
```

따라서 하나의 PyCharm 창에서 두 서버를 독립적으로 실행할 수 있습니다.

---

# 9. 두 서버 동시에 실행하기

가장 쉬운 방법은 먼저:

```text
FastAPI 8001
```

을 실행합니다.

정상이라면 콘솔에 대략 다음 내용이 표시됩니다.

```text
Uvicorn running on http://127.0.0.1:8001
Application startup complete.
```

그다음 Run Configuration을:

```text
Django 8000
```

으로 변경하여 실행합니다.

정상이라면:

```text
Starting development server at http://127.0.0.1:8000/
```

가 나타납니다.

PyCharm 하단의 **Run** 창에는 두 실행 프로세스가 존재하게 됩니다.

```text
Run

├─ FastAPI 8001
│   └─ Uvicorn running...
│
└─ Django 8000
    └─ Starting development server...
```

# 10. Compound Configuration을 만들면 더 편리함

매번 두 서버를 따로 실행하기 번거롭다면 **Compound Configuration**을 만들 수 있습니다.

```text
Run
 → Edit Configurations...
 → +
 → Compound
```

이름을:

```text
Django + FastAPI
```

로 설정하고 기존에 만든:

```text
Django 8000
FastAPI 8001
```

두 Configuration을 추가합니다.

그러면 최종적으로:

```text
Django + FastAPI ▶
```

한 번만 실행해도 두 서버를 함께 실행할 수 있습니다.

이 방식은 현재 프로젝트처럼 **Django와 FastAPI를 하나의 시스템으로 개발할 때 특히 편리합니다.**

---

# 11. Django와 FastAPI의 `.env`도 분리

Interpreter뿐만 아니라 환경변수도 분리하는 것이 좋습니다.

Django:

```text
final
└─ django_project
   └─ .env
```

예:

```env
DB_NAME=django_ai_db
DB_USER=root
DB_PASSWORD=1234
DB_HOST=127.0.0.1
DB_PORT=3306

FASTAPI_BASE_URL=http://127.0.0.1:8001
```

FastAPI:

```text
final
└─ fastapi_project
   └─ .env
```

예:

```env
OPENAI_API_KEY=본인의_OpenAI_API_Key

DB_NAME=django_ai_db
DB_USER=root
DB_PASSWORD=1234
DB_HOST=127.0.0.1
DB_PORT=3306

DJANGO_BASE_URL=http://127.0.0.1:8000
```

두 프로젝트가 동일한 MySQL을 사용하는 경우 **DB 이름과 접속정보를 동일하게 설정**합니다.

# 12. 실행 순서

처음 프로젝트를 설정할 때는 다음 순서를 권장합니다.

```text
① MySQL Server 실행
        ↓
② Django migration 확인
        ↓
③ FastAPI 8001 실행
        ↓
④ FastAPI 정상 확인
        ↓
⑤ Django 8000 실행
        ↓
⑥ Django 로그인/게시판 확인
        ↓
⑦ RAG 색인
        ↓
⑧ Django 화면에서 RAG 질의
        ↓
⑨ 멀티모달 AI 테스트
```

FastAPI 확인은 브라우저에서 Swagger를 열어 확인할 수 있습니다.

```text
http://127.0.0.1:8001/docs
```

Django는:

```text
http://127.0.0.1:8000
```

으로 접속합니다.

## 핵심 정리

따라서 PyCharm에서 중요한 것은 **`final`이라는 하나의 프로젝트에 Interpreter 두 개를 동시에 적용한다는 개념이 아니라**, 다음처럼 이해하는 것입니다.

```text
PyCharm에서 열기
C:\LLM_workspace\final
        │
        ├───────────────┐
        ▼               ▼
django_project      fastapi_project
        │               │
        ▼               ▼
Django .venv        FastAPI .venv
        │               │
        ▼               ▼
Django 8000         FastAPI 8001
Run Config          Run Config
        │               │
        └───────┬───────┘
                ▼
        Compound Configuration
          Django + FastAPI
```

즉, **상위 `final` 폴더 하나를 PyCharm에서 열고 → `.venv`는 두 개 생성 → Interpreter도 두 개 등록 → Run Configuration별로 해당 Interpreter를 지정 → 필요하면 Compound로 두 서버를 동시에 실행**하면 됩니다.
