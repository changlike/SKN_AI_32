

| 구분      | 명령어                                      | 기능              |
| ------- | ---------------------------------------- | --------------- |
| root 전환 | `sudo -i`                                | root 계정으로 전환    |
| 파일 복사   | `cp /etc/services /root/vi_practice.txt` | 실습 파일 생성        |
| 파일 확인   | `ls -l /root/vi_practice.txt`            | 파일 존재 확인        |
| vi 실행   | `vi /root/vi_practice.txt`               | 파일 편집 시작        |
| 입력      | `i`                                      | 커서 앞에서 입력       |
| 입력      | `a`                                      | 커서 뒤에서 입력       |
| 새 줄 입력  | `o`                                      | 아래에 새 줄 생성 후 입력 |
| 명령모드    | `ESC`                                    | 입력모드 → 명령모드     |
| 이동      | `h` `j` `k` `l`                          | 왼쪽/아래/위/오른쪽 이동  |
| 줄 이동    | `0` / `$`                                | 줄 처음/끝으로 이동     |
| 단어 이동   | `w` / `b`                                | 다음/이전 단어로 이동    |
| 페이지 이동  | `Ctrl+f` / `Ctrl+b`                      | 다음/이전 페이지       |
| 처음/끝    | `gg` / `G`                               | 파일 맨 위/맨 아래     |
| 문자 삭제   | `x`                                      | 문자 1개 삭제        |
| 단어 삭제   | `dw`                                     | 단어 삭제           |
| 줄 삭제    | `dd`                                     | 현재 줄 삭제         |
| 여러 줄 삭제 | `5dd`                                    | 5줄 삭제           |
| 실행 취소   | `u`                                      | 이전 작업 취소        |
| 다시 실행   | `Ctrl+r`                                 | 취소한 작업 복원       |
| 줄 복사    | `yy`                                     | 현재 줄 복사         |
| 여러 줄 복사 | `5yy`                                    | 5줄 복사           |
| 붙여넣기    | `p` / `P`                                | 아래/위에 붙여넣기      |
| 검색      | `/ssh`                                   | `ssh` 문자열 검색    |
| 다음 검색   | `n`                                      | 다음 검색 결과        |
| 이전 검색   | `N`                                      | 이전 검색 결과        |
| 줄 번호 표시 | `:set number`                            | 라인 번호 켜기        |
| 줄 번호 해제 | `:set nonumber`                          | 라인 번호 끄기        |
| 특정 줄 이동 | `:120`                                   | 120번째 줄 이동      |
| 저장      | `:w`                                     | 파일 저장           |
| 종료      | `:q`                                     | vi 종료           |
| 저장 후 종료 | `:wq`                                    | 저장하고 종료         |
| 저장 후 종료 | `:x`                                     | 저장하고 종료         |
| 강제 종료   | `:q!`                                    | 변경사항 저장하지 않고 종료 |
