인라인 스타일시트 적용 연습 페이지

html 시작태그에 style 속성(attribute)을 사용해서 직접 태그에 css 를 적용하는 방식

인라인 스타일시트는 일회용임, 여러 태그에 반복 사용은 못 함

모든 html 태그에 사용할 수 있는 속성들이 있음

  • id="아이디명" : 아이디명은 문서 안에서 유일한 이름이어야 함
  • class="클래스명" 또는 class="클래스명 하위클래스명" : 여러 태그에 같은 클래스명을 지정할 수 있음. 하나의 그룹으로 묶어줄 때 이용함
  • style="css속성:값;css속성2:값;css속성3:값;.........." : 인라인 스타일시트 적용시 사용함
  • name="이름" : 필요시 같은 이름이 여러번 사용될 수도 있음
