위치 관련 스타일 속성 연습 페이지

position 속성은 태그의 위치를 어떻게 지정할지 방식을 지정하는 속성이다.
적용할 수 있는 값은 absolute(절대위치), relative(상대위치), fixed(고정)를 사용할 수 있다. absolute 는 원래 태그가 표시될 위치를 무시하고, 브라우저 페이지영역 좌측상단 (left top)에서 부터의 위치 지정을 의미하는 방식임
relative 는 원래 태그가 표시될 위치를 기준으로 지정하는 방식을 의미함
fixed 는 태그 위치를 고정시킬 때 사용함. 화면 스크롤시에도 위치가 움직이지 않게 됨
