# 1. 회원가입 양식 Form 만들기

새 파일 만들기 : members/forms.py
=> 회원 가입 폼 설정
=> 로그인 폼 설정

# 2. 회원 가입 View 작성
members/views.py
=> 회원 가입 요청 처리 뷰
=> 로그인 요청 처리 뷰
=> 로그아웃 요청 처리 뷰 (단, 로그인이 필수임)

# 3. 회원 서비스 url 만들기 (해당 앱에서 라우터 등록임)

members/urls.py
=> 회원 가입 요청 라우터 등록 : /members/signup/
http://localhost:8000/members/singup/
=> 로그인 요청 라우터 등록 : /members/login/
=> 로그아웃 요청 라우터 등록 : /members/logout/

# 4. 프로젝트 URL 과 연결
config(or 프로젝트명)/urls.py

=> path 에 include 모듈 임포트 추가
=> members/urls.py 를 path() 로 추가 등록함


# 5. 템플릿 파일 작성하기

templates/members/signup.html 만듦
templates/members/login.html 작성

# 6. 회원가입 페이지 실행 확인

```터미널
python manage.py runserver
```
